# TCP/IP Security Lab

## Overview

This lab focused on understanding the TCP/IP protocol suite and common network attack techniques. The objective was to analyze packet behavior and observe how network protocols operate in real-world environments.

## Environment

* Ubuntu Linux
* Docker
* Virtual Network Environment

## Skills Demonstrated

* TCP/IP Analysis
* Packet Inspection
* Network Security
* Protocol Analysis

## Tasks Completed

### Packet Analysis

Captured and examined network traffic to observe TCP/IP communications.

### Protocol Investigation

Analyzed TCP handshakes, packet delivery, and network interactions.

### Network Attack Exercises

Observed how attackers can manipulate or interfere with network communications.

### Traffic Monitoring

Used packet capture tools to inspect protocol behavior and identify abnormal activity.

## Key Takeaways

* TCP/IP forms the foundation of modern networking.
* Understanding packet flow is essential for network defense.
* Traffic analysis is a valuable skill for security operations and incident response.

## Tools Used

* Wireshark
* Linux
* Docker
* TCP/IP Utilities
