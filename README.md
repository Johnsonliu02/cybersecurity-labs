# Cybersecurity Labs

This repository contains hands-on cybersecurity projects completed through the SEED Labs platform. These labs focus on web application security, network security, Linux security, and attack analysis in controlled environments.

## Skills Demonstrated

* SQL Injection
* Cross-Site Scripting (XSS)
* DNS Security
* TCP/IP Analysis
* Linux Security
* Network Traffic Analysis
* Vulnerability Assessment
* Secure Coding Concepts

## Tools and Technologies

* Wireshark
* Nmap
* Docker
* Linux
* MySQL
* Apache
* Firefox
* curl

## Projects

### SQL Injection Attack Lab

* Exploited SQL injection vulnerabilities in a vulnerable web application.
* Demonstrated authentication bypass and unauthorized database access.
* Evaluated defensive measures including prepared statements and parameterized queries.

### Cross-Site Scripting (XSS) Lab

* Executed reflected and stored XSS attacks in a controlled environment.
* Analyzed client-side security risks and mitigation strategies.

### Local DNS Attack Lab

* Investigated DNS spoofing attacks and domain resolution vulnerabilities.
* Evaluated the impact of malicious DNS responses on network traffic.

### TCP/IP Security Lab

* Analyzed network communications and packet behavior.
* Investigated common network attack techniques and protocol interactions.

### Environment Variables and SET-UID Lab

* Examined Linux privilege management and environment variable security.
* Analyzed risks associated with privileged program execution.
