# Local DNS Attack Lab

## Overview

This lab examined DNS spoofing attacks and weaknesses in domain name resolution. The objective was to understand how attackers can manipulate DNS responses and redirect users to malicious destinations.

## Environment

* Ubuntu Linux
* Docker
* DNS Services
* Networked Virtual Environment

## Skills Demonstrated

* DNS Analysis
* DNS Spoofing
* Network Security
* Traffic Inspection

## Tasks Completed

### DNS Spoofing

Configured malicious DNS responses to redirect users to attacker-controlled resources.

### Traffic Observation

Monitored DNS traffic and analyzed how name resolution requests are processed.

### Attack Validation

Verified that manipulated DNS records successfully redirected client requests.

### Defensive Analysis

Studied techniques used to mitigate DNS-based attacks.

## Key Takeaways

* DNS is a critical component of internet communications.
* DNS manipulation can facilitate phishing and credential theft.
* Secure DNS configurations help prevent spoofing attacks.
