# Environment Variables and SET-UID Lab

## Overview

This lab explored Linux privilege management and the security implications of environment variables and SET-UID programs. The objective was to understand how elevated privileges can be abused when programs are not securely designed.

## Environment

* Ubuntu Linux
* Docker

## Skills Demonstrated

* Linux Security
* Privilege Escalation Concepts
* Access Control
* Secure System Administration

## Tasks Completed

### Environment Variable Manipulation

Examined how environment variables influence program behavior.

### SET-UID Analysis

Investigated how SET-UID programs execute with elevated privileges.

### Security Testing

Observed scenarios where insecure configurations could lead to privilege escalation.

### Defensive Measures

Reviewed secure coding and system administration practices for privileged programs.

## Key Takeaways

* Improper privilege management can create serious security risks.
* Environment variables can influence privileged program execution.
* Principle of least privilege is critical for secure system design.
